✈️ ตั้งค่าการแจ้งเตือน Telegram (Telegram Alert)

ส่งภาพเปรียบเทียบ (ภาพเป้าหมาย vs ภาพตรวจพบสด) พร้อมระบุ % ความเหมือน และชื่อเป้าหมายไปยัง Telegram ทันที

วิธีขอ: ทักแชทหา @BotFather ใน Telegram พิมพ์ /newbot แล้วคัดลอก HTTP API Token มาวาง
วิธีดู ID: ทักหาบอท @userinfobot หรือดึงบอทเข้ากลุ่มแล้วพิมพ์ข้อความ
ระยะเวลาหน่วงระหว่างการแจ้งเตือนแต่ละครั้ง เช่น 5 วินาที จะทำให้ได้รับภาพหลายมุมเมื่อตรวจพบเป้าหมายต่อเนื่องใน Hitlist (ปรับได้ตั้งแต่ 1 วินาทีขึ้นไป แนะนำ 3 - 10 วินาที)
ระบบจะไม่ส่ง Telegram เมื่อ AI มั่นใจต่ำกว่าค่านี้ เพื่อลดการแจ้งเตือนผิดจากเงา แสง หรือวัตถุที่คล้ายคน (แนะนำอย่างน้อย 50%)
